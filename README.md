# Foundation English Interactive Book

A–C production prototype for Institute students.

Features:
- Mobile-friendly page-based reader
- Letter and vocabulary pronunciation
- Arabic dictionary
- Visual IPA references
- Saves the student's last page on the device
- Full-screen reader and swipe navigation
- Installable PWA shell with offline page caching
- Automatic GitHub Pages deployment from `main`
