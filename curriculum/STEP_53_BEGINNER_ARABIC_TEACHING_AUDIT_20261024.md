# Arabic-first teaching scaffolds for beginner STEP learners

**Date:** 2026-10-24. **Scope:** all 53 currently published STEP lessons (45 Grammar, 8 Writing Analysis), without changing source-backed questions or learner progress.

## Why this was needed

The actual protected lesson `first-conditional` contains abbreviated rules like `If + present simple`, `will + V1` and a repeated instruction “طبقها بحسب معنى الجملة”. For a learner who is still building basic English, this can look like memorization symbols without understanding.

## Changes

1. Add a **consistent four-part Arabic-first block** immediately before the existing detailed explanation in every protected student lesson: meaning and purpose in plain Arabic, simple sentence construction, an original teacher-written English example with an Arabic translation, and one common trap.
2. Publish instructor-written teaching scaffolds for each of the **53 published taxonomy slugs** as presentation-only JavaScript, independent of answer keys. The underlying learning objectives and original exercises are preserved.
3. The First Conditional's **three stages** also show an Arabic breakdown of If/condition, main clause/result, and use of can/provided, with semantically precise examples; distinguish `present simple` (المضارع البسيط), `V1` (الفعل في المصدر) and `will` as a future/modal marker.
4. Decode **nine First Conditional two-field rule captions** with real Arabic explanations instead of repeating the placeholder “طبقها بحسب معنى الجملة”. Preserve the correct caveat: the if-clause **normally** has present simple for First Conditional, not a categorical ban on will in all contexts.
5. Add a student-controlled short terminology glossary, Arabic path labels for conditional stages, LTR English patterns, RTL Arabic translation, mobile responsive styles.
6. Cover the curriculum list with a static audit test, and verify the first conditional UI and layout in Playwright at 390px and 1280px.

## Educational boundaries

The new examples and beginner wording are **instructor-authored explanations**, not claimed copied questions from STEP source PDFs or a replacement for the original full lesson material. The original published teaching, questions, keys and progress remain source-backed and unchanged. Future per-stage instructional refinement remains possible through the existing owner Studio workflow.

## Publication verification

Publish only when release quality gates pass; keep student attempts, exam results, review states and original question banks unchanged.
